# Arcane: The Fractured Realm

Браузерный 2D survival roguelite про мага, созданный на движке Godot 4.6 (GDScript) с целевым экспортом в Web (GL Compatibility).

---

## Текущий статус разработки

- **Этап 0 (Проверка проекта):** Завершён. Проверена версия Godot (4.6.2-stable), настроен рендерер GL Compatibility, определена структура директорий и настройки отображения (1280x720, `canvas_items`).
- **Этап 1 (Игровая основа):** Завершён.
  - Реализована замкнутая арена с коллизией стен и визуальной сеткой (`scenes/arena/arena.tscn`).
  - Реализован маг-игрок с 8-направленным нормализованным перемещением, камерой сверху со сглаживанием, системой здоровья, i-frames (неуязвимость после получения урона) и визуальной вспышкой при попадании (`scenes/player/player.tscn`).
  - Реализован базовый враг с поведением преследования игрока и контактным уроном (`scenes/enemies/basic_enemy.tscn`).
  - Реализован спавнер врагов (`scripts/enemies/spawn_manager.gd`) для тестирования кайтинга и выживания.
  - Реализован HUD с полосой здоровья (HP), таймером выживания и экраном гибели с возможностью быстрого перезапуска (`scenes/ui/hud.tscn`).
- **Этап 2 (Автоматические атаки и прокачка):** Завершён.
  - **Выбор целей:** Реализован статический сервис `TargetSelector` для поиска ближайших врагов.
  - **Магическая стрела (Magic Bolt):** Дальняя автоматическая атака. Выпускает чародейские снаряды с автоприцелом в ближайшего врага. До 5 уровней прокачки (увеличение урона, снижение перезарядки, до 3 снарядов веером).
  - **Рунический клинок (Runic Blade):** Ближняя орбитальная защита. Призывает вращающиеся рунические клинки вокруг мага с защитой от непрерывного тикового урона (per-enemy hit cooldown 0.45с). До 5 уровней прокачки (до 3 клинков, ускорение вращения, урон 38).
  - **Опыт и кристаллы:** При гибели враги сбрасывают лазурные кристаллы опыта (`XPGem`). Кристаллы притягиваются к магу при приближении и поглощаются.
  - **Повышение уровня (Level Up):** При наборе опыта игра ставится на паузу и открывает окно выбора из 3 карточек (`LevelUpPanel` и `RewardGenerator`). Карточки предлагают новые заклинания, улучшения текущих заклинаний или пассивные характеристики (сила заклинаний +15%, скорость бега +12%, ускорение перезарядки -12%, здоровье +25).
  - **HUD обновлён:** Добавлены индикатор текущего уровня (`УР. X`) и верхняя шкала опыта (XP Bar).

## Управление в игре

| Действие | Клавиши |
|---|---|
| Перемещение | **WASD** или **Стрелки клавиатуры** |
| Автоатака | Срабатывает автоматически по ближайшим врагам |
| Выбор улучшения | **Клик мыши** по одной из 3 карточек при Level Up |
| Перезапуск забега | **R** (на экране гибели или кнопка на экране) |
