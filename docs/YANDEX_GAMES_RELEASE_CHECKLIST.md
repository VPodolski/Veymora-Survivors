# Чек-лист проверки и публикации игры на платформе Яндекс Игры

## Проект: Veymora Survivors
**Версия игры:** 0.3 (с полной интеграцией SDK Яндекс Игр)  
**Движок:** Godot Engine 4.6.2 (GL Compatibility / WebGL2, single-threaded)  
**Платформы:** Desktop (Яндекс Браузер, Chrome, Firefox, Edge, Opera, Safari) и Mobile (Android / iOS мобильные браузеры)

---

## 1. Проверка Web-сборки и архива

- [x] **Размер архива:** Суммарный размер сборки (`index.wasm` ~36.5 МБ, `index.pck` ~480 КБ, `index.js` ~315 КБ) составляет **~38.5 МБ**, что строго удовлетворяет ограничению платформы (<100 МБ).
- [x] **Именование файлов:** Все файлы в архиве названы строго латинскими буквами без пробелов и спецсимволов (`index.html`, `index.js`, `index.wasm`, `index.pck`, `index.png`, `index.icon.png`, `index.apple-touch-icon.png`).
- [x] **Корневой файл:** Главная страница расположена строго в корне архива с именем `index.html`.
- [x] **Структура zip-архива:** При распаковке zip-архива файлы должны попадать сразу в корень, а не во вложенную папку `build/web/`.

## 2. Инициализация и жизненный цикл SDK

- [x] **Подключение SDK скрипта:** В теге `<head>` страницы `index.html` подключен официальный скрипт:
  ```html
  <script src="https://yandex.ru/games/sdk/v2"></script>
  ```
- [x] **Инициализация `YaGames.init()`:** Вызывается при запуске Web-версии в изолированном мосте `YandexGamesBridge`.
- [x] **LoadingAPI.ready():** Вызывается строго после полной загрузки ресурсов и отображения стартового меню (`MainMenu._ready()` -> `call_deferred("_notify_game_ready")`), а не во время темного экрана загрузки движка.
- [x] **GameplayAPI.start():** Вызывается при входе в игровое состояние забега (`GameFlowController.STATE_PLAYING`).
- [x] **GameplayAPI.stop():** Вызывается при выходе из активного боя: открытие меню паузы, переход на экран результатов, экран выбора арены или главное меню.
- [x] **Офлайн / Fallback режим:** При локальном запуске без SDK (в редакторе, standalone-тестах или без интернета) мост автоматически переходит в `is_local_mode = true` без ошибок и подвисаний.

## 3. Управление паузой и звуком (Multi-Reason Mutex)

- [x] **Независимые причины паузы (`PauseManager`):**
  - `REASON_USER`: ручная пауза игрока (клавиша Escape или кнопка на экране).
  - `REASON_BROWSER_FOCUS`: потеря фокуса окна браузера или свернутая вкладка (`window.onblur`).
  - `REASON_PLATFORM`: внешнее событие паузы от платформы.
  - `REASON_ADVERTISEMENT`: во время показа Interstitial или Rewarded рекламы.
  - `REASON_MODAL`: модальные окна (выбор улучшения при level up, сундук с артефактом, диалог «Второй шанс»).
- [x] **Защита от нежелательного возобновления:** Если игрок поставил игру на паузу вручную (`REASON_USER`), возвращение фокуса в окно браузера (`window.onfocus`) снимает только причину `BROWSER_FOCUS`, но **НЕ** возобновляет бой, пока игрок сам не нажмет кнопку «Продолжить».
- [x] **Временное приглушение звука (`set_temporary_mute`):** При потере фокуса браузера, паузе платформы или показе рекламы весь звук глушится через системную шину (`AudioServer.set_bus_mute(0, true)`). Пользовательские настройки громкости (`master_volume`, `sfx_volume`) сохраняются неизменными.

## 4. Реклама и монетизация

- [x] **Межстраничная реклама (Interstitial):**
  - Вызывается в естественных паузах между сессиями: при перезапуске забега или возврате в меню с экрана результатов (`ResultsScreen._navigate_with_ad`).
  - Встроенный таймер предотвращает спам рекламой (минимальный интервал 60–90 секунд).
  - Во время показа блокируется игровой процесс и глушатся звуки.
- [x] **Реклама за вознаграждение (Rewarded — «Второй шанс»):**
  - Доступна строго **один раз за забег** при первой гибели мага.
  - Воскрешение выдается **ТОЛЬКО** при явном подтверждении колбэка `onRewarded`.
  - При закрытии рекламы без просмотра вознаграждение не начисляется, игрок направляется на стандартный экран результатов.
  - После успешного воскрешения: восстановление 50% максимального здоровья, 2.5 секунды неуязвимости (i-frames) и защитная отталкивающая ударная волна.

## 5. Мобильная адаптация и ориентация экрана

- [x] **Ориентация:** Базовое разрешение 1280x720 (альбомная 16:9).
- [x] **Предупреждение о портретной ориентации (`OrientationWarning`):** На смартфонах при повороте в портретный режим отображается оверлей с просьбой повернуть устройство в альбомную ориентацию.
- [x] **Виртуальный аналоговый джойстик (`VirtualJoystick`):** Расположен в левом нижнем углу экрана. Активируется на сенсорных устройствах, поддерживает плавный векторный ввод и ограничение радиуса (deadzone + clamping).
- [x] **Кнопка мобильной паузы:** Кнопка «⏸» в правом верхнем углу HUD с увеличенной областью нажатия (touch target >= 44x44px).
- [x] **Предотвращение браузерных конфликтов:** CSS-свойства `touch-action: none`, `user-select: none`, `-webkit-touch-callout: none` блокируют контекстные меню по долгому тапу, зум щипком и pull-to-refresh.

## 6. Сохранения и синхронизация (SaveManager + Cloud)

- [x] **Гостевой режим:** Игра полноценно сохраняет прогресс в локальное хранилище (`user://save_data.json` / IndexedDB) без обязательной авторизации.
- [x] **Облачная синхронизация:** При наличии авторизации в Яндекс Играх данные загружаются через `ysdk.getPlayer().getData()`.
- [x] **Безопасное слияние (Cloud Merge Strategy):**
  - Пустое облако никогда не затирает локальные достижения гостя.
  - Открытые арены (`unlocked_arenas`) объединяются операцией Union (объединение множеств).
  - Рекорды и счетчики (`best_survival_time`, `total_runs`, `bosses_defeated`, `total_kills`) берутся как максимум (`max(local, cloud)`).
  - Открытия Кодекса и цели Атласа объединяются без дубликатов.

## 8. Таблица лидеров (Leaderboard)

- [x] **Название лидерборда:** «Лучшие исследователи Разлома» (`rift_explorers`).
- [x] **Формула очков:** `time_survived * 10 + kills * 5` (учитывает и мастерство выживания, и агрессивность боя).
- [x] **Отправка:** Результат автоматически отправляется на платформу в момент показа экрана результатов (`ResultsScreen.display_stats`).
- [x] **Безопасность:** Если игрок не авторизован или играет офлайн, отправка пропускается без сбоев.
