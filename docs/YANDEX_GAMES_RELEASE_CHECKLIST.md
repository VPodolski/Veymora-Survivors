# Veymora Survivors — Чек-лист проверки и публикации на платформе Яндекс Игры

## Проект: Veymora Survivors
**Версия игры:** 0.3 (с полной интеграцией SDK Яндекс Игр)  
**Движок:** Godot Engine 4.6.2 (GL Compatibility / WebGL2, single-threaded)  
**Платформы:** Desktop (Яндекс Браузер, Chrome, Firefox, Edge, Safari) и Mobile (Android / iOS мобильные браузеры)  
**Система статусов:**
- `[IMPLEMENTED]` — реализовано в кодовой базе проекта
- `[AUTOMATED_TESTED]` — подтверждено автоматическими тестами (14/14 сьютов пройдено)
- `[BROWSER_TESTED]` — проверено локально в веб-браузере
- `[CONSOLE_CONFIGURED]` — требует настройки в панели разработчика Яндекс Игр
- `[YANDEX_TESTED]` — проверено в песочнице / iframe Яндекс Игр
- `[NOT_VERIFIED]` — ожидает загрузки черновика и модерации

### 1.2. Инициализация SDK и Loading API (P0.1)

  ```html
  <script src="https://yandex.ru/games/sdk/v2"></script>
  ```
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Разделение готовности игры и SDK:** Флаги `is_sdk_initialized` и `is_game_ready` разделены в `YandexGamesBridge`.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] [BROWSER_TESTED] Строго однократный вызов `LoadingAPI.ready()`:** Вызов происходит только при одновременной готовности стартовой сцены (`MainMenu._ready()`) и SDK платформы.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Защита от зависаний инициализации:** Внедрен аварийный таймаут (4000 мс в JS, 5.0 с в GDScript) и `Promise.race()` (2000 мс) на получение объекта `Player`.

### 1.3. Облачные сохранения и авторизация (P0.2)
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] [BROWSER_TESTED] Полная поддержка гостевого режима:** Прогресс сохраняется в `user://save_data.json` (IndexedDB) без принудительной авторизации.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Загрузка облачных данных:** При инициализации и после авторизации автоматически запрашиваются облачные данные.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Безопасное слияние (`merge_with_cloud`):**
  - Пустое облако никогда не затирает локальные достижения гостя.
  - Арены объединяются операцией Union.
  - Рекорды и счетчики рассчитываются по формуле `max(local, cloud)`.
  - Открытия Кодекса и цели Атласа объединяются без дубликатов.
  - Результат слияния немедленно сохраняется локально.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Дебаунсинг сохранений:** Запись в облако буферизуется с задержкой 1.5 с (`schedule_cloud_save()`) с возможностью немедленного принудительного сброса (`flush_cloud_save()`).
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] [BROWSER_TESTED] UI авторизации в Главном меню:** В правом верхнем углу меню размещены статус аккаунта и кнопка авторизации с динамической сменой состояния.

### 1.4. Централизованная синхронизация Gameplay API (P0.3)
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Единая точка синхронизации:** Сигналы смены состояния `GameFlowController` и `PauseManager` обрабатываются в `YandexGamesBridge.reconcile_gameplay_state()`.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Точный жизненный цикл геймплея:**
  - `gameplay_start()` вызывается строго при `STATE_PLAYING` и отсутствии активных пауз.
  - `gameplay_stop()` вызывается при ручной паузе, открытии модалок сундука/улучшений, гибели, победе, переходе на экран результатов и в меню.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] Исключение ложных стартов:** При смене сцен состояние меняется до очистки причин паузы, что предотвращает паразитные вызовы старта геймплея.

### 1.5. Управление паузой и звуком (P0.4)
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] [BROWSER_TESTED] Реестр независимых причин паузы (`PauseManager`):**
  - `REASON_USER`: ручная пауза игрока (кнопка Esc или экранная кнопка паузы).
  - `REASON_BROWSER_FOCUS`: потеря фокуса вкладки/окна (`window.onblur`).
  - `REASON_PLATFORM`: внешняя пауза от платформы.
  - `REASON_ADVERTISEMENT`: во время воспроизведения рекламы.
  - `REASON_MODAL`: модальные окна выбора карт, наград и возрождения.
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] [BROWSER_TESTED] Защита от нежелательного возобновления:** Возврат фокуса (`window.onfocus`) снимает только `REASON_BROWSER_FOCUS`, но оставляет бой на паузе, если игрок поставил её вручную (`REASON_USER`).
- [x] **[IMPLEMENTED] [AUTOMATED_TESTED] [BROWSER_TESTED] Полное приглушение звука и остановка SFX:** При любой активной паузе или показе рекламы мастер-шина глушится (`AudioServer.set_bus_mute(0, true)`), а все активные звуковые эффекты мгновенно останавливаются (`AudioManager.stop_all_sfx()`). Пользовательские уровни громкости сохраняются.

- [ ] **[NOT_VERIFIED] Проверка в тестовом фрейме (Sandbox iframe):**

  - Убедиться, что событие `LoadingAPI.ready()` фиксируется платформой без задержек.
