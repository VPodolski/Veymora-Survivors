# Arcane: The Fractured Realm

Браузерный 2D survival roguelite про мага, созданный на движке Godot 4.6 (GDScript) с целевым экспортом в Web (GL Compatibility).

---

## Текущий статус разработки

- **Этап 0 (Проверка проекта):** Завершён. Проверена версия Godot (4.6.2-stable), настроен рендерер GL Compatibility, определена структура директорий и настройки отображения (1280x720, `canvas_items`).
- **Этап 1 (Игровая основа):** Завершён.
  - Реализована замкнутая арена с коллизией стен и визуальной сеткой (`scenes/arena/arena.tscn`).
  - Реализован маг-игрок с 8-направленным нормализованным перемещением, камерой сверху со сглаживанием, системой здоровья, i-frames (неуязвимость после получения урона) и визуальной вспышкой при попадании (`scenes/player/player.tscn`).
  - Реализован базовый враг с поведением преследования игрока и контактным уроном (`scenes/enemies/basic_enemy.tscn`).
  - Реализован спавнер врагов (`scripts/enemies/spawn_manager.gd`) для тестирования кайтинга и выживания.
  - Реализован HUD с полосой здоровья (HP), таймером выживания и экраном гибели с возможностью быстрого перезапуска (`scenes/ui/hud.tscn`).
  - Все базовые числовые параметры вынесены в ресурсы (`PlayerStats`, `EnemyStats`).

## Архитектура проекта

```text
res://
├── project.godot                  # Конфигурация проекта (главная сцена, слои коллизий, разрешение)
├── README.md                      # Документация и инструкции запуска
├── scenes/
│   ├── main/
│   │   └── main.tscn              # Главная точка входа игры
│   ├── arena/
│   │   └── arena.tscn             # Арена со стенами и визуалом
│   ├── player/
│   │   └── player.tscn            # Игрок (CharacterBody2D, Camera2D, коллизия, визуал)
│   ├── enemies/
│   │   └── basic_enemy.tscn       # Преследующий враг (CharacterBody2D, Area2D атаки, визуал)
│   └── ui/
│       └── hud.tscn               # Интерфейс: HP бар, таймер, экран поражения
├── scripts/
│   ├── game/
│   │   └── main.gd                # Управление запуском, связка сигналов, ввод
│   ├── arena/
│   │   └── arena.gd               # Генерация коллизий границ и отрисовка пола
│   ├── player/
│   │   ├── player_controller.gd   # Логика движения, здоровье, получение урона
│   │   ├── player_stats.gd        # Ресурс параметров игрока
│   │   └── player_visual.gd       # Отрисовка силуэта мага и эффекта вспышки
│   ├── enemies/
│   │   ├── enemy_controller.gd    # ИИ преследования, нанесение урона, смерть
│   │   ├── enemy_stats.gd         # Ресурс параметров врага
│   │   ├── enemy_visual.gd        # Отрисовка силуэта врага и вспышки попадания
│   │   └── spawn_manager.gd       # Спавн базовых врагов
│   └── ui/
│       └── hud_controller.gd      # Обновление здоровья, времени, экран Game Over
├── resources/
│   ├── player/
│   │   └── default_player_stats.tres # Дефолтные параметры мага (HP: 100, Скорость: 230)
│   └── enemies/
│       └── basic_enemy_stats.tres    # Дефолтные параметры врага (HP: 30, Скорость: 110, Урон: 12)
└── tests/
    └── test_stage1.gd             # Автоматизированный тест Этапа 1 (запуск headless)
```

## Управление в игре

| Действие | Клавиши |
|---|---|
| Перемещение | **WASD** или **Стрелки клавиатуры** (диагонали нормализованы) |
| Перезапуск забега | **R** (на экране гибели или кнопка на экране) |

## Запуск проекта

### 1. Запуск через редактор Godot
1. Откройте Godot 4.6+.
2. Импортируйте/выберите папку проекта `veymora-survivors`.
3. Нажмите клавишу **F5** (или кнопку «Запустить проект» в правом верхнем углу). Главная сцена: `res://scenes/main/main.tscn`.

### 2. Запуск через консоль / CLI
```powershell
godot.exe --path "C:\Users\Aiono\Documents\veymora-survivors"
```

### 3. Запуск автоматических тестов Этапа 1
```powershell
godot_console.exe --headless --path "C:\Users\Aiono\Documents\veymora-survivors" -s "res://tests/test_stage1.gd"
```
