# Arcane: The Fractured Realm

Браузерный 2D survival roguelite про мага, созданный на движке Godot 4.6 (GDScript) с целевым экспортом в Web (GL Compatibility / WebGL2).

---

## Текущий статус разработки (Этапы 0–6 Завершены)

- **Этап 0 (Проверка проекта):** Завершён. Проверена версия Godot (4.6.2-stable), настроен рендерер GL Compatibility, определена структура директорий и настройки отображения (1280x720, `canvas_items`, `keep`).
- **Этап 1 (Игровая основа):** Завершён. Замкнутая арена с коллизией стен, маг-игрок с 8-направленным нормализованным перемещением, камера со сглаживанием, преследующие враги, урон, i-frames, HUD со шкалой здоровья и таймером, экран окончания забега.
- **Этап 2 (Автоматические атаки и прокачка):** Завершён. Система автоприцеливания `TargetSelector`, заклинание дальнего боя «Магическая стрела», орбитальная защита «Рунический клинок» с персональным кулдауном тиков по врагам, сферы опыта с магнетизмом, экран повышения уровня (Level Up) с паузой и выбором из 3 карточек, верхняя полоса XP.
- **Этап 3 (Синергии, артефакты и эволюция):** Завершён.
  - Статусы врагов (`charged`, `slowed`, `unstable`).
  - Боевые реакции: Чародейский резонанс (AoE-ударная волна), Ледяной скол (веер ледяных осколков), Грозовая цепь.
  - 3 артефакта: *Песочные часы обратного течения* (бумеранг-пробитие), *Обсидиановое сердце* (урон от низкого HP + волна отталкивания при ударе), *Компас разломов* (метки нестабильности и взрывы при гибели).
  - Эволюция: Магическая стрела (ур. 5) + Песочные часы = **«Возвращающийся разлом»** (призматические возвращающиеся стрелы с бесконечным пробиванием).
- **Этап 4 (Полировка боя и оптимизация):** Завершён.
  - Всплывающие числа урона с цветовым кодированием (обычный урон, криты, реакции).
  - Искры при попаданиях и эффекты растворения пустоты при гибели врагов.
  - Микро-полоски здоровья над ранеными противниками.
  - Тряска экрана (Screen Shake) при получении урона и срабатывании обсидиановой волны.
  - Оптимизация толпы (до 90+ врагов одновременно) и объединение сфер опыта при высокой плотности.
  - Очистка снарядов за пределами арены.
- **Этап 5 (Короткий законченный забег):** Завершён.
  - Заклинание **«Ледяной шторм» (Ice Storm):** AoE-зона замедления и периодического урона.
  - Заклинание **«Клеймо смерти» (Death Mark):** Точечное проклятие приоритетных целей (+40%...+80% к получаемому урону, взрыв «Жатва душ» при гибели).
  - **Сундуки с сокровищами (`Chest`):** Гарантированная выдача недостающего артефакта или исцеления/опыта.
  - **Элитный враг («Бронированный Осквернитель»):** 180 HP, золотая аура, гарантированный сброс сундука.
  - **Босс («Повелитель Разлома»):** 700 HP, статус-бар босса в HUD, механика рывка и залп теневых снарядов.
  - Экран итогов забега (`SummaryScreen`) со статистикой выживания, уровня и поверженных боссов.
  - Система сохранений (`SaveManager`): сохранение рекордов и профиля в `user://save_data.json`.
- **Этап 6 (Подготовка браузерной сборки):** Завершён.
  - Проверена совместимость с WebGL2 / GL Compatibility.
  - Сконфигурирован пресет Web-экспорта (`export_presets.cfg`) в однопоточном режиме (`variant/thread_support=false`), гарантирующем запуск на любых хостингах без необходимости заголовков COOP/COEP.
  - Настроен адаптивный ресайз канваса (`canvas_resize_policy=2`) и автоматический фокус клавиатуры (`focus_canvas_on_start=true`).
  - Сгенерирована рабочая веб-сборка в `build/web/` (`index.html`, `index.js`, `index.wasm`, `index.pck`).
  - Проверена раздача через локальный HTTP-сервер.

## Управление в игре

| Действие | Клавиши |
|---|---|
| Перемещение | **WASD** или **Стрелки клавиатуры** |
| Автоатака | Автоматически наводится и стреляет по ближайшим целям |
| Выбор улучшения | **Клик ЛКМ** по одной из 3 карточек при Level Up |
| Открытие сундука | Подойти вплотную к сундуку |
| Перезапуск забега | Клавиша **R** или кнопка на экране завершения забега |

## Запуск тестов

Для запуска всех автоматических тестов в headless-режиме:

```powershell
# Консольный бинарник Godot 4
$GODOT = "C:\Users\Aiono\Downloads\Godot_v4.6.2-stable_win64.exe\Godot_v4.6.2-stable_win64_console.exe"
$PROJECT = "C:\Users\Aiono\Desktop\Veymora-Survivors"

# Запуск тестов каждого этапа
& $GODOT --headless --path $PROJECT -s "res://tests/test_stage1.gd"
& $GODOT --headless --path $PROJECT -s "res://tests/test_stage2.gd"
& $GODOT --headless --path $PROJECT -s "res://tests/test_stage3.gd"
```

## Запуск игры

### 1. Десктопный запуск (Редактор / Godot)
```powershell
godot.exe --path "C:\Users\Aiono\Desktop\Veymora-Survivors"
```

### 2. Браузерный запуск (Web / HTML5)
Сборка расположена в директории `build/web/`.

Для локальной проверки запустите любой статический HTTP-сервер (в браузере прямым открытием файла `file:///` WebAssembly не запускается из соображений безопасности браузеров):

```powershell
# Запуск локального веб-сервера через Python:
cd "C:\Users\Aiono\Desktop\Veymora-Survivors\build\web"
python -m http.server 8000

# Затем откройте в браузере:
# http://localhost:8000
```

### 3. Публикация на itch.io / GitHub Pages
1. Упакуйте содержимое папки `build/web/` в zip-архив (файлы `index.html`, `index.js`, `index.pck`, `index.wasm` и сопутствующие иконки должны лежать в корне архива).
2. На [itch.io](https://itch.io) создайте новый проект, выберите тип **HTML**, загрузите zip-архив и отметьте чекбокс **«This file will be played in the browser»**.
3. Установите рекомендуемый размер окна **1280 × 720** (или отметьте полноэкранный режим). Так как `variant/thread_support=false`, игра запустится мгновенно без настройки специальных COOP/COEP заголовков.
