# Veymora Survivors — Версия 0.3

Браузерный 2D survival roguelite про мага, созданный на движке Godot 4.6 (GDScript) с целевым экспортом в Web (GL Compatibility / WebGL2).

Репозиторий: https://github.com/VPodolski/Veymora-Survivors

---

## 1. Концепция и цель версии 0.3

**Veymora Survivors 0.3** превращает игровой прототип в законченную игру с полноценным пользовательским циклом:
$$\text{Главное меню} \longrightarrow \text{Выбор арены} \longrightarrow \text{Загрузка} \longrightarrow \text{Забег} \longrightarrow \text{Экран результатов} \longrightarrow \text{Повтор / Арена / Меню}$$

### Ключевые приоритеты версии 0.3:
1. **Полноценный игровой цикл:** Атмосферное главное меню с антропоморфным силуэтом мага, экран выбора пространственного разлома, интерактивный экран загрузки и подробный экран итогов.
2. **Разнообразие пространственных разломов (Арены):**
   - **Забытый лес (Forgotten Forest):** Стартовая арена, сбалансированные волны, рунические источники усиления заклинаний.
   - **Ледяной некрополь (Frost Necropolis):** Вторая играбельная арена v0.3, динамические очаги вечной мерзлоты (Frost Hazard Zones) с телеграфом и замедлением на 35%.
   - **Пепельная цитадель (Ash Citadel):** Заблокированное превью для v0.4 с уникальным описанием, условиями открытия и опасностями.
   - **Разлом Бездны (Void Rift):** Заблокированное превью для v0.4 с гравитационными и временными аномалиями.
3. **Глубокий анализ синергий на экране результатов:**
   - Детальный расклад по каждой сработавшей синергии (количество активаций, нанесённый урон).
   - Выделение самой эффективной («ключевой») синергии забега.
   - Процентный вклад синергий в общий нанесённый магом урон.
4. **Централизованные настройки графики и звука:**
   - Раздельные ползунки общей громкости (Master) и громкости эффектов (SFX).
   - Переключение интенсивности визуальных эффектов (Стандартные / Сниженные).
   - Тумблеры тряски экрана (Screen Shake), отображения чисел урона (Damage Numbers) и вертикальной синхронизации (VSync).
5. **Сохранение прогресса SaveManager v2:**
   - Автоматическая миграция сохранений (v1 $\to$ v2) без потери открытий игрока.
   - Учёт индивидуальной статистики по каждой арене (забеги, победы, рекорд времени, убийства).
   - История последних 10 забегов с детальными сводками.
6. **Техническое совершенство:** 100% прохождение всех 13 автоматических тестовых наборов и стабильный WebGL2-экспорт.

## 2. Игровой цикл и экраны версии 0.3

### 1. Главное меню (Main Menu)
- **Визуальный стиль:** Атмосферный тёмно-магический архив, процедурные парящие частицы маны, вращающиеся концентрические рунические кольца и узнаваемый силуэт мага в остроконечной шляпе с посохом и пульсирующей сферой.
- **Навигация:** «⚔ ВЫБОР АРЕНЫ», «📖 КОДЕКС И АТЛАС», «⚙ НАСТРОЙКИ», «✦ УПРАВЛЕНИЕ И ПРАВИЛА».
- **Сводка метапрогресса:** Всего забегов, рекорд выживания, повержено боссов, количество открытых арен.

### 2. Выбор пространственного разлома (Arena Select)
- Карточки 4 арен с уникальной цветовой гаммой, глифами и сложностью.
- Отображение особенностей, угроз и персональной статистики по выбранной арене.
- Защита заблокированных арен с понятным описанием условий открытия.

### 3. Интерактивный экран загрузки (Loading Screen)
- Вращающийся рунический спиннер и индикатор готовности разлома.
- Информация о выбранной арене и случайные полезные геймплейные советы по синергиям и тактике.

### 4. Экран результатов (Results Screen)
- Исход забега: победный золотой стяг «РАЗЛОМ ЗАКРЫТ!» или рубиновый «МАГ ПОГИБ».
- Полная статистика забега: выжитое время, достигнутый уровень, уничтожено теней (обычные, элита, боссы), суммарный урон, собранный опыт и количество артефактов.
- **Аналитическая панель синергий:** подсчёт всех комбинаций, нанесённого ими урона и доли от общего урона мага.
- Кнопки: «⚔ Повторить забег», «🌀 Выбрать арену», «📖 Кодекс и Атлас», «🏠 В главное меню».

## 3. Магические синергии и эволюции

### Синергии стихий:
- **Чародейский резонанс:** Аркан по заряженной цели $\to$ дуговой импульс 18 урона по области 85px и перенос заряда.
- **Ледяные осколки:** Лёд по замедленной цели $\to$ раскол на 3 пробивающих кристальных осколка по 14 урона.
- **Грозовая дуга:** Молния по заряженной цели $\to$ каскадный цепной разряд по цепочке врагов.
- **Взрыв нестабильности:** Гибель помеченной цели $\to$ фиолетовый разломный взрыв 25 урона по площади 90px.
- **Паровой разлом:** Огонь по замедленной цели $\to$ густое облако пара с постоянным уроном 20/сек.
- **Термодинамическая перегрузка:** Огонь по заряженной цели $\to$ вспышка сверхвысокой температуры на 38 урона с поджогом.

### Высшие эволюции заклинаний:
1. **Возвращающийся разлом:** Магическая стрела (ур. 5) + Песочные часы $\to$ бесконечное пробивание и возврат стрел к магу.
2. **Абсолютный буран:** Ледяной шторм (ур. 5) + Ледяное ядро $\to$ снежная буря радиусом 230px с уроном 32/тик и заморозкой.
3. **Инфернальная сверхновая:** Огненная сфера (ур. 5) + Обсидиановое сердце $\to$ гигантская огненная звезда с бесконечным пробиванием и уроном 50.
4. **Ярость Небес:** Грозовой разряд (ур. 5) + Громоотвод $\to$ штормовой каскад небесных молний (до 7 скачков, урон 45).

## 4. Управление в игре

| Действие | Клавиши |
|---|---|
| Перемещение | **WASD** или **Стрелки клавиатуры** |
| Атака | Автоматическое наведение и применение заклинаний |
| Выбор улучшения / артефакта | **Клик ЛКМ** по карточке |
| Пауза / Настройки / Кодекс | Клавиша **ESC** |
| Быстрый перезапуск | Клавиша **R** |

## 5. Автоматическое тестирование и проверка качества

В репозитории реализован полный набор из 13 автономных тестовых сюит, запускаемых через Godot Headless CLI:

```powershell
# Полная проверка пользовательского цикла v0.3 (GameFlow, Арены, Результаты, Синергии, Настройки)
& Godot_v4.6.2-stable_win64_console.exe --headless --path . -s res://tests/test_v03_game_flow.gd

# Проверка боевой логики синергий и лимитов эффектов v0.2
& Godot_v4.6.2-stable_win64_console.exe --headless --path . -s res://tests/test_v02_synergies_and_effects.gd

# Проверка механики сундуков из 3 артефактов и очередей окон
& Godot_v4.6.2-stable_win64_console.exe --headless --path . -s res://tests/test_chest_and_refinements.gd

# Проверка Web-экспорта и артефактов
& Godot_v4.6.2-stable_win64_console.exe --headless --path . -s res://tests/test_stage6.gd
```

### Запуск Web-сборки локально:
```powershell
cd build/web
python -m http.server 8000
# Откройте в браузере: http://localhost:8000
```
Сборка выполнена в однопоточном режиме (`variant/thread_support=false`), поэтому она гарантированно работает на любом веб-сервере (GitHub Pages, itch.io) без необходимости настройки специальных заголовков `COOP/COEP`.
