# Veymora Survivors

Браузерный 2D survival roguelite про мага, созданный на движке Godot 4.6 (GDScript) с целевым экспортом в Web (GL Compatibility / WebGL2).

Репозиторий: https://github.com/VPodolski/Veymora-Survivors

---

## Текущий статус разработки (Стабилизация & Visual Polish)

Проведена техническая стабилизация кодовой базы и визуальная полировка по результатам Code Review:

### Критические исправления (P1)
1. **Вражеские снаряды наносят урон игроку:**
   - Внедрена система фракций `Projectile.Faction { PLAYER, ENEMY }`.
   - Вражеские снаряды (теневые клыки босса «Повелитель Разлома») используют `collision_mask = 1`, наносят урон ровно один раз, создают искры удара и уничтожаются при контакте с игроком.
   - Снаряды игрока защищены от нанесения урона самому игроку.
2. **Последовательная обработка множественных Level Up:**
   - В `LevelUpPanel` реализована FIFO-очередь отложенных повышений уровней (`pending_levels`).
   - При пересечении нескольких порогов XP одним подбором игра остаётся на паузе и последовательно отображает каждый выбор улучшений без потери уровней и дублирования панелей.
3. **Корректная статистика убийств и модель `RunStats`:**
   - Выделена независимая модель состояния забега `RunStats`, отслеживающая время выживания, общее число убийств, убийства элитных врагов и босса.
   - Смерть врагов через `SpawnManager.enemy_killed` связана с регистрацией убийств. Повторные вызовы смерти идемпотентны (каждый экземпляр учитывается ровно один раз).
4. **Разделение проверки конфигурации и артефактов сборки Web:**
   - В `tests/test_stage6.gd` разделена проверка конфигурации проекта/пресета (которая всегда валидна на чистом clone) и проверка артефактов сборки при их наличии.

### Стабильность и корректность систем (P2)
1. **Единый лимит активных врагов (`max_enemies = 90`):**
   - Лимит строго соблюдается во всех путях спавна (обычные волны, рой, элита).
   - Для босса предусмотрен приоритетный резерв: если лимит достигнут к моменту появления босса, удаляется самый дальний базовый враг.
2. **Очистка cooldown синергий:**
   - В `SynergyEngine` добавлен автоматический клинап таймеров реакций при удалении врага из дерева (`tree_exited`), явный метод `clear_target_cooldowns(target)` и периодическая очистка устаревших записей (`prune_stale_cooldowns`).
3. **Безопасная работа с сохранениями (`SaveManager`):**
   - Добавлена версия формата `version = 1`.
   - Валидация типов, диапазонов значений и безопасные дефолты при повреждённом или частично заполненном JSON.
   - Атомарная запись через временный файл (`save_data.json.tmp` $\to$ `save_data.json`).
4. **Отделение баланса от логики:**
   - Параметры спавна вынесены в Godot Resource `SpawnConfig` (`resources/game/default_spawn_config.tres`).
5. **Физическое отталкивание врагов:**
   - Метод `apply_knockback(impulse)` в `EnemyController` использует векторную скорость и затухание в `_physics_process()`, уважая стены арены и `move_and_slide()`.
6. **Оптимизация конденсации сфер опыта:**
   - Убран $O(N)$ обход при спавне каждого отдельного кристалла. Конденсация запускается централизованно через таймер `MainGame` при превышении порога в 65 сфер.

### Визуальная полировка (Visual Polish)
- **Узнаваемый силуэт мага (`player_visual.gd`):** остроконечная шляпа с сияющей золотой звездой, мантия с контрастной лазурной каймой, парящее покачивание (idle bobbing), направленный взгляд и рунический круг под ногами.
- **Различие игровых объектов:**
  - Базовые враги: шипастые теневые сущности с горящими алыми глазами.
  - Элитные враги: массивные золотые броневые пластины и рубиновое ядро.
  - Босс: гигантский монолит с 4 вращающимися осколками разлома и оком пустоты.
  - Снаряды босса: острые теневые кинжалы с контрастным огненным следом.
- **Телеграфы атак босса:** предупреждающий визуальный заряд и импульс за 0.45с до рывка.
- **Снижение визуального шума:** лимит одновременно отображаемых цифр урона (до 24), фильтрация мелких чисел при плотном бое.

## Управление в игре

| Действие | Клавиши |
|---|---|
| Перемещение | **WASD** или **Стрелки клавиатуры** |
| Автоатака | Автоматически наводится и стреляет по ближайшим целям |
| Выбор улучшения | **Клик ЛКМ** по одной из 3 карточек при Level Up |
| Открытие сундука | Подойти вплотную к сундуку |
| Перезапуск забега | Клавиша **R** или кнопка на экране завершения забега |

## Архитектура проекта

```text
res://
├── project.godot                  # Конфигурация проекта (Veymora Survivors, 1280x720, GL Compatibility)
├── export_presets.cfg             # Пресет экспорта в Web (HTML5/WASM, однопоточный)

├── build/
│   └── web/                       # Скомпилированная Web/WASM сборка
│       ├── index.html             # Веб-страница с canvas и адаптивным контейнером
│       ├── index.js               # Загрузчик и мост JavaScript/WASM
│       ├── index.pck              # Запакованные ресурсы игры (199 KB)
│       └── index.wasm             # Бинарный модуль движка Godot (35.95 MB)
├── scenes/
│   ├── main/main.tscn             # Главная сцена и цикл игры
│   ├── arena/arena.tscn           # Арена со стенами и процедурной сеткой
│   ├── player/player.tscn         # Игрок (CharacterBody2D, Camera2D, AbilityController)

│   │   ├── elite_enemy.tscn       # Элитный враг (дроп сундука)
│   │   └── boss_enemy.tscn        # Босс Повелитель Разлома
│   ├── abilities/

│   │   ├── runic_blade.tscn       # Орбитальные клинки
│   │   ├── ice_storm.tscn         # Ледяной шторм (AoE)
│   │   └── death_mark.tscn        # Клеймо смерти (амплификация урона)
│   ├── combat/projectile.tscn     # Снаряд (с поддержкой фракций PLAYER / ENEMY)
│   ├── pickups/
│   │   ├── xp_gem.tscn            # Вращающийся кристалл опыта с магнетизмом
│   │   └── chest.tscn             # Сундук с артефактами
│   └── ui/
│       ├── hud.tscn               # Интерфейс HP, XP, таймер, полоса босса, итоги
│       └── level_up_panel.tscn    # Панель выбора улучшений с очередью

│   │   ├── main.gd                # Главный контроллер, спавн, таймеры
│   │   ├── run_stats.gd           # Модель статистики забега (убийства, время, элита, босс)
│   │   └── save_manager.gd        # Атомарное сохранение и санитизация user://save_data.json
│   ├── resources/
│   │   └── spawn_config.gd        # Ресурс параметров баланса волн и врагов
│   ├── player/
│   │   ├── player_controller.gd   # Управление магом, физика, отталкивание от артефактов
│   │   └── player_visual.gd       # Уникальный силуэт мага, мантия, шляпа, bobbing
│   ├── combat/
│   │   ├── projectile.gd          # Поведение снарядов игрока и врагов
│   │   ├── combat_effects.gd      # Ударные волны, молнии, оптимизированные числа урона
│   │   └── target_selector.gd     # Поиск ближайших целей
│   ├── synergies/

│   ├── enemies/

│   │   ├── boss_controller.gd     # ИИ босса, телеграфы атак, снаряды фракции ENEMY
│   │   └── spawn_manager.gd       # Контроль лимита max_enemies, спавн волн/элиты/босса
│   └── ui/
│       ├── hud_controller.gd      # Обновление HUD, предупреждение о низком HP
│       └── level_up_panel.gd      # Очередь множественных level-up
└── tests/
    ├── test_stage1.gd             # Тест игровой основы
    ├── test_stage2.gd             # Тест способностей и опыта
    ├── test_stage3.gd             # Тест синергий и артефактов
    ├── test_evolution_firing.gd   # Тест эволюции заклинания
    ├── test_stage4.gd             # Тест эффектов и орды
    ├── test_stage5.gd             # Тест забега, сундуков и босса
    ├── test_stage6.gd             # Тест конфигурации Web-экспорта
    ├── test_code_review_regressions.gd # Регрессионный тест всех правок Code Review
    └── test_performance.gd        # Бенчмарк производительности (30, 60, 90, 120 врагов)
```
